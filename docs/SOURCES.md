# Project materials

The method diagram, recovery sequence, results, and real-robot images come from the ACRO manuscript. The stand-mixer video is a recorded ACRO rollout. Its Q trace and the displayed physical action counts refer to the same execution; the high-resolution frames replay its saved actions from another camera.

The real-robot image shows ACRO's Franka Panda evaluations on pick and place, cube stacking, and button pressing. Sources for the benchmark overview used in the paper are documented in [the preprint source](https://github.com/JunHoo-Lee/ACRO/blob/main/paper/ASSET_SOURCES.md).

The article layout is inspired by [VISTA](https://vista-research.github.io/) and its [page repository](https://github.com/vista-research/vista-research.github.io). ACRO’s HTML, CSS, and JavaScript were authored for this page. The [VISTA implementation](https://github.com/joshhhhhan/VISTA) was reviewed for its package and execution organization.
